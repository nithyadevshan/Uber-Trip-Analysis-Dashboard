🚖 Uber Trip Analysis Dashboard

An interactive Power BI dashboard designed to analyze ride-sharing operations, customer demand patterns, revenue trends, and vehicle utilization.

 Key Features
- Booking Trend Analysis
- Revenue Monitoring
- Trip Distance Analysis
- Vehicle Performance Tracking
- Payment Method Analysis
- Demand Pattern Identification
- Location-Based Analytics
- Interactive KPI Monitoring

Tools Used
- Power BI
- DAX
- Power Query
- Data Modeling
